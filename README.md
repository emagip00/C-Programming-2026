## 버그 수정본 (`_수정.c`)

원본 과제 파일은 그대로 두고, 버그를 고친 사본을 같은 폴더에
`원본이름_수정.c` 로 함께 두었습니다. 고친 부분마다 `// [수정]` 주석으로
이유를 적어 두었고, 전체 내역은 **[BUGFIX.md](BUGFIX.md)** 에 있습니다.

주요 수정 사항은 0 으로 나눗셈 크래시 1건, 무한루프 2건,
틀린 값을 조용히 출력하던 문제 5건, 아무것도 출력되지 않던 문제 1건입니다.

```bash
# 원본과 수정본 비교
diff "week07/04_성적_평균_계산.c" "week07/04_성적_평균_계산_수정.c"
```
