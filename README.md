## Week 06: 다중 조건문(`switch ~ case`) 및 사용자 정의 함수

조건에 따라 실행 흐름을 여러 갈래로 나누는 `switch ~ case` 문과 함수 분리를 학습하는 단원입니다.

* **학년 판별 예제 (`switch ~ case`)**: 입력받은 정수값에 따라 1~3학년 메시지를 분기 출력하며, 이외의 입력은 `default`로 예외 처리.


* **연도/월별 마지막 날짜 계산 예제**:
* `isleapyear()`: 윤년 여부를 판단하여 `1` 또는 `0`을 반환하는 함수.


* `exerc()`: 입력받은 월에 따라 `switch ~ case` 문으로 28일/29일(윤년 적용), 30일, 31일 일수를 계산 및 출력.
